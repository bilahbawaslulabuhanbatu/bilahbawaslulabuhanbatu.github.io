# BILAH — Bawaslu Kabupaten Labuhanbatu

Website: https://rangkutiray3.github.io/chat/

Website diterbitkan otomatis melalui GitHub Actions. Berkas release/site.part-* membentuk satu arsip terverifikasi SHA256. Source aplikasi tersedia dalam source/bilah-source.tar.gz; aset public (logo, maskot, worker PDF) tersedia dalam arsip website.

Database, autentikasi dan layanan AI tetap di Supabase. Tidak ada AI_API_KEY atau service-role key di repositori. Halaman admin memerlukan login dan kebijakan akses database tetap berlaku.
